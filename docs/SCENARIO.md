## 8. 誤った推理が成立してしまう理由
- 足跡が濡れている → 「雨の中の侵入者」：雨上がり時刻とにおいを確認しないと外部犯説に流れる。
- 靴下 → 「ゴンザレス犯行」：乾き具合とほこりを見ないと事件時刻と結びつく。
- 映像欠落 → 「ボス・トン犯行」：彼は管理室から一歩も出ていない。止めた理由（依頼）を突き止めないと主犯扱いになる。
- 在庫記録 → 「シェフが盗んだ」：事件前の不一致は味見。盗難とは別問題。
- 止まった時計 → 「ゴンザレスは8時に広場＝アリバイ成立」：写真の撮影時刻が鍵。
- マダムの「8:15の影」→ 犯行時刻を8:15と誤認：カメラは8:12に再開し、誰も映っていない。

## 9. 章構成と分岐
- 第1章：現場検証（保管室・展示台・監視室・広場）、容疑犬への初聞き込み → **最初に疑う犬を選ぶ**（ゴンザレス／ボス・トン／シェフ／マダム）。選んだ犬の信頼度が下がり、第2章冒頭の反応が変わる。
- 第2章：アリバイ調査（厨房・鍵番小屋・執務室が解放）、証言の矛盾指摘で秘密が解放。
- 第3章：捜査ルートを一つ選ぶ。
  - A 映像と時刻（監視室）：停止ログ・断片映像
  - B 在庫と輸送（厨房・搬入口）：運行表・だし汁
  - C 足跡と物証（地下入口）：巻尺メモ・壊れた扉
  - D 町長とマダム（執務室・VIPテント）：宣伝計画書・秘密協定書
- 第4章：地下倉庫（共通：輸送伝票・輸送箱の番号）→ **誰を信頼するか**（ブヒ田／マダム／ボス・トン／シェフ）で他ルートの証拠を一つ補える → **輸送伝票を公表するか伏せるか**。
- 第5章：最終推理（犯犬→動機→トリック→決定的証拠）。
